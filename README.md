# Pie Warrior
## Project Info
The project is made in Godot using GDScript.   
It was made over 15 hours by adding various scenes and nodes. The main UI is controlled by the control scene and the main gameplay by the level scene.
Currently no executable is available, to play it you must go to
 Itch.io-[Pie Warrior](https://salprokite.itch.io/pie-warrior)                  

 ### Setup
 To open the project and edit it you must - 
 - Download the game.zip from exports folder (not the export.zip or any other file)
 - Extract it in a folder
- Go to Godot and click import and navigate to project.godot in the folder where you extracted the zip
- Voila! The project is now running in your engine edit it all you want

### Game
It is a game where you collect various fruits and bake them into pies to become the pie warrior. I personally consider being over 10 pies as a pie warrior, though it varies on taste. The instructions are -
- Use A for left, D for right and Space for Jump
- Jump on trampolines to reach greater heights (or between to reach even greater heights)
- DONT AND I MEAN DONT touch the spikes or the saw
- Collect all the fruit you can and bake them to pies in the bakery
- The level is intentonally short and hard (though possible)
